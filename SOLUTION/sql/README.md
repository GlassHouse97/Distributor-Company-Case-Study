# SQL Queries

This folder contains the reproducible SQLite SQL for all four final analyses. Filenames use the same numeric prefixes as the solution documents.

| Prefix | Purpose |
| --- | --- |
| `01_` | Segment revenue, gross profit, margin, growth contribution, and validation |
| `02_` | Customer and segment concentration, thresholds, HHI, and validation |
| `03_` | Lifecycle status, revenue-at-risk baseline, segment risk, outreach, and validation |
| `04_` | Revenue, gross profit, margin, seasonality, and validation |

The queries use recognized accounting `Period` for financial reporting and the transaction’s historical customer class for segment analysis. Question-specific Markdown files document assumptions and link each query to its exported result.
