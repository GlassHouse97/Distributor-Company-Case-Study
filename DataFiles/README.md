# Data Files

These are the data files used for this case study project. [Download the data](https://www.kaggle.com/datasets/chrisdelgado3301/distributor-company-portfolio-dataset)

## Important Notice

You will notice that there is **no `TotalSales` table** included in this folder, even though it is referenced extensively throughout the SQL queries.

The original `TotalSales` table is too large to be distributed as a single CSV file within this repository.

If you would like to fully replicate the analysis, you will need to:

- Reconstruct the `TotalSales` table using your own approach
- Generate synthetic transactional data
- Or build a scaled version of the dataset for practice purposes

Consider this an additional analytical exercise — how you design and structure your `TotalSales` table is part of the challenge ;)
