# Portfolio Deliverables

This folder contains the two polished reviewer entry points:

- `Distributor_Case_Study_Report.docx` — the business-facing case-study report for hiring managers and executive readers.
- `Distributor_Case_Study_Analysis.xlsx` — the analyst companion with formula-linked summary metrics, filterable result tables, outreach priorities, and validation evidence.

Both deliverables are generated from the validated CSV outputs in `SOLUTION/outputs/`. The Word report contains no customer names, and the workbook uses anonymized labels only where the analysis requires customer-level ranking or outreach prioritization.
