# Portfolio Downloads

This folder contains the polished reviewer downloads linked from the root README:

- `Distributor_Case_Study_Report.docx` - editable version of the business report.
- `Distributor_Case_Study_Analysis.xlsx` - analyst companion with formula-linked summary metrics, filterable result tables, outreach priorities, and validation evidence.

The report contains no source-company or customer names. The workbook uses anonymized labels where the analysis requires customer-level ranking or outreach prioritization.
