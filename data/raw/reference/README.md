# Reference Data

These files are the scrubbed public reference layer for the case study.

- `CustomerSegmentationData.csv` maps historical transaction class codes to descriptions.
- `CustomerData.csv` provides anonymized current customer attributes for optional geography and current-state analysis.
- `schema.xlsx` preserves the original source-field definitions.

Historical reporting continues to use the customer class stored on each transaction. Current customer attributes never rewrite prior financial records.
